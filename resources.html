降雨観測から侵食モデル、将来予測まで、研究で使用している主要なデータとツールをまとめています。

Key datasets and tools used in my research, from rainfall observations to erosion modelling and future projections.

気象・気候データWeather & climate data

  • 気象庁二重偏波レーダー観測データJMA dual-polarization weather-radar observations — 降雨粒子の特性や降雨エネルギーの推定に利用used to estimate raindrop properties and rainfall energy
  • Disdrometer地上観測データ（Parsivel）Ground-based disdrometer observations (Parsivel) — 雨滴粒径分布と降雨運動エネルギーの解析に利用used to analyze drop size distributions and rainfall kinetic energy
  • d4PDF — 大規模アンサンブル将来気候予測データセットlarge-ensemble climate-projection dataset
  • XRAIN — 国土交通省の高解像度気象レーダー観測データhigh-resolution weather-radar observations from MLIT, Japan

モデル・ソフトウェアModels & software

  • WEPP — プロセスベースの土壌侵食予測モデルprocess-based soil-erosion prediction model
  • CLIGEN — WEPPで用いる確率的気象生成モデルstochastic weather generator used with WEPP
  • BPCDG — 観測気象データからWEPP用のbreakpoint climate dataを生成するツールBreakpoint Climate Data Generator for creating WEPP climate input from observed weather data

Radar & DSD tools

  • Py-ART — 気象レーダーデータの読み込み・解析weather-radar data processing and analysis
  • DISDRODB — Disdrometerデータの標準化・解析standardization and analysis of disdrometer data
  • PyXRAIN — XRAINデータ処理XRAIN data processing

AI tools

  • ChatGPT — 文章整理、解析方針の検討、コード作成支援support for writing, analysis planning, and coding
  • Codex — コード実装・修正支援support for code implementation and revision
